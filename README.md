# Procesador de Horas Laborales

Este repositorio contiene una aplicación de línea de comandos y una interfaz Streamlit para calcular horas diurnas, nocturnas y sobretiempos a partir de archivos Excel.

## Ejemplos de uso

### Procesamiento por consola
```
python process_horas.py --input datos.xlsx --output reporte.xlsx
```

### Aplicación Streamlit
```
streamlit run "app (2).py"
```
